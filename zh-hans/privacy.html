隐私

简而言之：本网站不会追踪你。

本网站

  • 无 Cookie、无统计分析、无广告、无账户。
  • 本网站托管于 GitHub Pages。GitHub 可能出于安全目的记录你的 IP 地址等技术数据；详见 GitHub 的隐私声明。
  • 字体从 Google Fonts 加载，你的浏览器获取字体时，Google Fonts 会收到你的 IP 地址。
  • 预告片是以隐私增强模式（youtube-nocookie.com）嵌入的 YouTube 视频，仅在你点击时加载。
  • 指向 Steam、Discord 和社交网络的链接会将你带到这些服务，并受其各自政策约束。

游戏

  • 设置、进度、贴纸以及你对使用条款的同意记录均保存在你电脑本地。
  • 在线合作使用 Steam；你的账户和匹配由 Steam 依据 Valve 的隐私政策处理。
  • 我们不出售个人数据。
